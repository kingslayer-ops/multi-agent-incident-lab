# Contributing

Contributions are welcome through focused issues and pull requests.

1. Fork the repository and create a descriptive branch.
2. Install backend and frontend dependencies as documented in `README.md`.
3. Keep safety policy deterministic and keep all executors sandboxed.
4. Add tests for workflow, persistence, provider, or API behavior you change.
5. Run the backend coverage gate and production frontend build before opening a pull request.

Please never commit credentials, production telemetry, customer data, or commands that mutate real infrastructure.
